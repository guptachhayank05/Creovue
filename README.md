# 🎬 Creovue – Talent & Opportunity Platform

Creovue is a role-based talent and opportunity platform designed for the film and entertainment industry. The platform connects **Artists / Users**, **Media Houses**, and **Production Houses** in one ecosystem, enabling seamless collaboration, hiring, and opportunity discovery.

This project was developed to simplify how talent and organizations interact in the entertainment space through a structured digital platform.

## 👥 User Roles & Modules

### 1️⃣ User / Artist
- Create profile
- Showcase skills / experience
- Apply for casting calls or opportunities
- Track applications

### 2️⃣ Media House
- Post creative opportunities
- Search suitable talent
- Manage applicants

### 3️⃣ Production House
- Publish projects / hiring needs
- Review candidate profiles
- Manage hiring workflows

---

## 🗄️ Database Design

Designed a relational PostgreSQL schema handling multiple entities such as:

- Users
- Roles
- Profiles
- Job Posts
- Applications
- Organizations

Focus was given to:

- Data integrity
- Efficient joins
- Optimized queries
- Maintainable relationships

---

## ⚙️ Backend Features

- Role-based authentication & authorization
- Input validation
- Global exception handling
- Modular layered architecture
- CRUD operations via REST APIs
- Clean response structure
